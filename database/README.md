# database

Thu muc nay danh cho cac tai nguyen lien quan den co so du lieu.

- `schema/`: tai lieu schema hoac script init
- `migrations/`: cac file migration
- `seeds/`: seed data dung cho local/dev/demo
- `docs/`: ERD, data dictionary, ghi chu nghiep vu

`apps/api-server/src/main/resources/data.sql` van duoc giu de backend hien tai chay binh thuong.
